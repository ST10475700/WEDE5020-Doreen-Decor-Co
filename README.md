# WEDE5020-Doreen-Decor-Co
Doreen Decor & Co is a decor business offering romantic setups, weddings and birthdays celebrations. This website presents the services, a photo gallery, an enquiry form and contact details so that clients can easily get in touch.

Features-
Responsive layout that works on desktops and tablets.
Services page with an enquiry form (name accepts letters only, contact method and extras options) 
Contact page with a contact form that sends an email to the business.
Dynamic content with a search function.
Gallery lightbox image viewer
Interactive map showing the business location
SEO: Page titles, meta descriptions, keywords and alt text on images.
Commented HTML, CSS and JavaScript.

Download or clone the repository.
